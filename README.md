About
----------------------

This Repository has 2 groups of projects:  

- A WPF app (here) that using the json config file generated by the editor apps here, jusxtaposed with specific event results, to generate certificates for competitors as a pdf that they can then print. Includes a graphic background image. Also support forwarding of the pdf via Outlook (Classic).
  - `GenerateCertificates/GenerateCertificatesLatest`
  - *There were some other similar versions that have now been deleted.*
- Editors that produce json files, as Certificate Metadata, as here consumed by `GenerateCertificatesLatest` and by the original PS version
<https://github.com/djaus2/AthleticsCertificateMaker>. All three editors produce the same json metadata for the generator, just different UIs.
  - `EditJason/FormEdit`: Simplest to use
  - `EditJason/FoldingEditor`: Complete structured Json fokding editor
  - `EditJason/TextEditor`: Raw Text Editor

Purpose
----------------------

- The generator app here, as well as the original project, [AthleticsCertificateMaker](https://github.com/djaus2/AthleticsCertificateMaker), read a json file to define the certificate metadata for an event.
  - Previously the certificate layout and content was defined by a Powershell script in the project `AthleticsCertificateMaker`.
- The editor apps will read in a existing config file as json, edit and save, Can also create a new one.
- The metadata contains information specific the event , such as the event name, date, location, and the layout of the certificate, including the background image and the position of text fields and their labels.

Included apps
-----------

This solution contains three editor applications and one generator application. Brief descriptions and where to run them follow.

- TxtEditor (TxtEditor\TxtEditor.csproj)
  - A simple raw text (JSON) editor for the certificate configuration. Features load, save, pretty-format and basic validation. Useful when you want to edit the JSON directly or start from a default document.
  - Run: set TxtEditor as the startup project in Visual Studio or dotnet run --project TxtEditor\TxtEditor.csproj

- FormEdit (FormEdit\FormEditCert.csproj)
  - A form-based editor that binds to a CertificateModel. Provides UI grids to edit CertificateText and CertificateFields, and common metadata (template file, CSV file, colors, flags). Produces the same JSON used by AthleticsCertificateMaker but with a user-friendly form interface.
  - Run: set FormEdit as the startup project in Visual Studio or dotnet run --project FormEdit\FormEditCert.csproj

- FoldingEditor (FoldingEditor\FoldingEditor.csproj)
  - A code-style JSON editor using AvalonEdit with syntax highlighting and folding. Good for large documents where folding and code-style editing help navigation. Supports load, save, pretty-format and JSON validation.
  - Run: set FoldingEditor as the startup project in Visual Studio or dotnet run --project FoldingEditor\FoldingEditor.csproj
- `GenerateCertificateApp`

- [GenerateCertificateAppLatest](https://github.com/djaus2/AthsCertificateEditors/tree/master/GenerateCertificateAppLatest)
  - The certificate generator app.
  - Run: set GenerateCertificateAppLatest as the startup project in Visual Studio.

Getting started

---------------

1. Clone the repository:
   git clone <https://github.com/djaus2/AthsCertificateEditors.git>

2. Open the solution in Visual Studio 2026:
   File → Open → Project/Solution → AthsCertificateEditors.slnx
   Or use the CLI:
   dotnet sln AthsCertificateEditors.slnx

3. Build:
   - Visual Studio: Build Solution
   - CLI: dotnet build

4. Run an editor:
   - 3 to choose from but ``FormEditCert is probably best.
   - Set the desired editor project as startup in Visual Studio and run.
   - Or run from the CLI: dotnet run --project <path-to-editor-project>
   - Load the same json file for editing or create a new one.
5. Run GenerateCerticateAppLatest
   - Load the json file created or edited in the previous step.
   - Adjust setting and generate the sample certicates.
      - Just use Outlook Save option until ready to send.
        - Nb Need Classic Outlook (16)
6. Need results as a CSV or tabbed separated file.
   - The CSV/tabbed separated file should have a header row with the following columns:
   - `Name`, `Distance`, `Position`, `Time`, `Event`, `Date`. The order of the columns does not matter, but the names must match exactly.
   - Whilst the event name is a field in the metadata it can be a a separate line in the CSV file.
   - The generator will use the event name from the metadata if it is not present in the CSV file.
   - Where multiple event titles are in the results, all results that follow will use that event name until another is read.
   - [Sample results file](results.csv)
